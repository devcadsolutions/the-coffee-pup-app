# AI Agent Guide for The Coffee Pup App

This folder contains guidance files for AI assistants working on The Coffee Pup App.

## Files

### agent.md
Defines the AI’s role, priorities, and response behavior.

### memory.md
Stores stable project context, product direction, and working principles.

### skills.md
Contains repeatable workflows for planning, designing, building, and debugging.

### tools.md
Lists project tools, commands, and important technical references.

### commands.md
Contains common prompt patterns and preferred task styles.

## Purpose
These files help the AI:
- understand the project faster
- follow the app’s product direction
- stay consistent in coding and planning
- provide more useful and less generic support

## How to Use
1. Keep these files updated as the app evolves
2. Add real stack/tool details to tools.md
3. Add project-specific decisions to memory.md
4. Add repeated workflows to skills.md
5. Expand commands.md with your usual requests

## Recommendation
As the project grows, split large skills into separate files inside `/agent/skills`.
