# Skills

## Plan Features
Use when defining new features for The Coffee Pup App.

### Steps
1. Clarify the feature goal
2. Identify the user action and expected result
3. Break the feature into UI, logic, backend, and data needs
4. Suggest the simplest useful version first
5. Recommend future improvements only after the core flow is clear

### Output
- Feature summary
- User flow
- Required screens/components
- Data/API needs
- Suggested implementation order

---

## Design Screens and UX
Use when improving app flows, layouts, or user experience.

### Steps
1. Identify the purpose of the screen
2. Define the main CTA
3. Reduce clutter
4. Group related content clearly
5. Ensure good hierarchy, spacing, and readability
6. Consider empty/loading/error states

### Output
- UX recommendations
- Layout structure
- Component suggestions
- Possible user pain points
- Improvements

---

## Build UI Components
Use when creating or refining app components.

### Steps
1. Define the component purpose
2. Keep props simple and reusable
3. Ensure consistent naming
4. Support common states
5. Keep styling maintainable

### Output
- Component structure
- Props
- Example usage
- Notes for reuse

---

## Debug App Issues
Use when the app has errors, bugs, or unexpected behavior.

### Steps
1. Describe the issue clearly
2. Identify likely causes
3. Check logs, state flow, API flow, and UI behavior
4. Narrow the issue to one layer
5. Suggest the fix
6. Explain how to verify the fix

### Output
- Probable cause
- How to test it
- Fix recommendation
- Code change if needed

---

## Organize Project Structure
Use when the codebase starts growing or feels messy.

### Steps
1. Review current folder structure
2. Group by feature or responsibility
3. Separate UI, logic, services, and utilities
4. Remove duplication
5. Standardize naming

### Output
- Suggested folder structure
- Refactor notes
- Naming guidance

---

## Prepare Product Tasks
Use when turning ideas into actionable work.

### Steps
1. Define the task clearly
2. State the expected output
3. Break work into small steps
4. Identify dependencies
5. Add acceptance criteria

### Output
- Task description
- Subtasks
- Acceptance criteria
- Notes and risks
