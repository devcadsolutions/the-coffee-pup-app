# Memory

## Project Name
The Coffee Pup App

## Project Purpose
The Coffee Pup App is a coffee-themed application with a cute, memorable brand identity. It should feel friendly, clean, modern, and easy to use.

## Core Product Direction
- Strong branding around coffee + pup personality
- Mobile-friendly user experience
- Smooth and simple user flows
- Visually appealing but not cluttered
- Features should feel playful but still polished

## Product Principles
- Keep the experience warm and welcoming
- Make the app intuitive for first-time users
- Keep screens uncluttered
- Favor simple flows over complex interactions
- Maintain consistent visual language

## Engineering Principles
- Use scalable folder structure
- Prefer reusable UI components
- Keep business logic separated from presentation
- Name files and components consistently
- Write code that is easy to maintain and extend

## UX Principles
- Clear call-to-actions
- Minimal friction in important flows
- Consistent spacing, typography, and component behavior
- Loading, empty, and error states should be handled properly
- Forms should be simple and understandable

## AI Assistance Preferences
- Help with both technical and product decisions
- Suggest cleaner structure when needed
- Give practical next steps
- When relevant, propose improvements in small, manageable steps
