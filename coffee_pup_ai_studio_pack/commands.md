# Commands

## Common Requests
- Plan the next feature for The Coffee Pup App
- Create a clean folder structure for this app
- Design the screen flow for this feature
- Build this UI component
- Review this code and improve it
- Debug this issue
- Suggest a better UX for this screen
- Create a database schema for this feature
- Generate API structure for this flow
- Write product task breakdowns
- Summarize what has been built so far
- Suggest improvements without rewriting everything
- Create release notes for the latest changes

## Preferred Behavior
When responding to commands:
- keep suggestions practical
- prefer simple implementations first
- explain tradeoffs when needed
- preserve working code unless a better structure is justified
